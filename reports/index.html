📋 About this project

Why I built this

I mentor 600+ DevOps engineers in FlipTheScript — Israel's largest DevOps community. The two questions I hear constantly are "what should I learn?" and "who actually hires juniors?"

Most career advice in tech is anecdotal. This platform replaces guessing with weekly data — what skills are actually demanded, what companies are actually hiring, what the junior pipeline really looks like.

How it works

Every morning, a free GitHub Action runs a Python script that scrapes 8 public job-board endpoints (LinkedIn guest API, Greenhouse boards of 30+ Israeli tech companies, RemoteOK public JSON, AllJobs, Drushim, Glassdoor, Jobmaster, Lever). Each posting is filtered for DevOps / SRE / Platform / Cloud roles in Israel, deduplicated across sources, then analyzed for skills, seniority, salary, hiring momentum, and junior-friendliness.

The output is committed back to a public GitHub repo and served from this site. Every weekly snapshot is preserved — so we can show real trends over time.

100% free, open, reproducible

No paid APIs. No SaaS subscriptions. No external dependencies — pure Python standard library. $0/month forever.

The full source code, scrapers, analysis engine, and weekly snapshots are public on github.com/OrelBello/devops-market-data. Fork it, audit it, build on top of it.

Honest limitations

  • Greenhouse + LinkedIn are our reliable sources; the others vary day-to-day
  • Salary disclosure is rare in Israel — we track it when explicitly stated
  • Junior matches require ≥2 DevOps stack items in the JD; some "junior" titles are filtered out
  • The "tracked cumulatively" counter started May 15 2026 when the daily cron began
